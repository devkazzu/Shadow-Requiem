# SHADOW REQUIEM Roadmap

## Milestones

- **v0.1 — prototype:** playable MVP vertical slice. Current milestone.
- **v0.2 — combat:** heavy attack, lock-on, parry, perfect parry, launch/juggle, refined hit-stop.
- **v0.3 — characters:** seven Nocturne commanders, switching, switch attacks, passives.
- **v0.4 — first map:** Shadow City headquarters, training room, mission board, NPC shops.
- **v0.5 — story:** dialogue system, choices, chapter transitions, skippable cutscenes.
- **v0.6 — boss system:** boss library, weak points, phase scripting, nightmare variants.
- **v0.7 — progression:** weapons, inventory, equipment, artifacts, skill trees.
- **v0.8 — optimization:** Android profiling, quality presets, asset streaming, memory budgets.
- **v0.9 — beta:** QA pass, accessibility pass, balancing, crash handling.
- **v1.0 — release:** stable Android launch candidate.
